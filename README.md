
# Productividad de Profesionales — Ajustes de Admin (no destructivo)

Este paquete reemplaza solo el `.py` agregando:
- **Configuración avanzada** (editar/fusionar/activar-desactivar Programas/Convenios/Instituciones/Profesionales/Pacientes).
- **Reportes extra** (Viáticos, Planificador y Papelería con descarga en Excel/CSV).
- Mantiene todo lo cargado: **no borra registros históricos**.

## Instrucciones
1. Haga backup con la pestaña **Respaldo** (o copie `productividad_*.db`).
2. Reemplace el archivo principal por `app_productividad_profesores_ADV.py` en su repositorio.
3. Mantenga el mismo `requirements.txt` que ya usa su app.
